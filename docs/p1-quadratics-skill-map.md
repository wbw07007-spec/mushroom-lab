## 第一组 · 教师对照及答题核算

目标仅为 **右边化零后确定左边带符号常数**。Homework Worked Example 1.1(a) 和 1A Q1(e) 训练完整解题，学生需先判断对等式两边执行的运算。这里固定整理后其余项，让学生独立写出常数，通过填空测量这一个动作。Homework 保留教材编号，采用独立编写的方程和解析。由单侧正整数起步，再处理负常数、两边都有一次项，最后纳入分数和一次项抵消。

| Homework 对照 | 新题 ID | 英文题目 | 核算答案 | 典型错答和可选提示 |
|---|---|---|---|---|
| Worked Example 1.1(a) / 1A Q1(e) | p1-quad-foundation-standard-1 | Write `x² + 4x + 7 = 12` in standard form `x² + 4x + c = 0`. Find `c`. | `7 − 12 = −5` | `5`。Check the order of the subtraction. Start with the constant already on the left. |
| 同上 | p1-quad-foundation-standard-2 | Write `2x² − x = −9` in standard form `2x² − x + c = 0`. Find `c`. | `0 − (−9) = 9` | `−9`。If you add −9 to the right-hand side, does it become zero? |
| 同上，延伸至两边的同类项 | p1-quad-foundation-standard-3 | Write `3x² + 5x − 4 = 2x − 10` in standard form `3x² + 3x + c = 0`. Find `c`. | `−4 − (−10) = 6` | `−14`。The right-hand constant is negative. What is −4 − (−10)? |
| 同上，延伸至分数 | p1-quad-foundation-standard-4 | Put `4x² + 3x − 5/2 = 3x − 3/4` in the form `4x² + c = 0`. Find `c`. | `−5/2 + 3/4 = −7/4 = −1.75` | `−13/4`。Check the sign when subtracting −3/4. Use 1/4 as the common unit. |

首组的期望错误是移项时丢掉负号、反向相减，以及把减去负数写成减去其绝对值。题目只验证独立算出的结果，教师可在纸笔任务中核对整条等式的书写。括号内常数、补偿常数、顶点和最值仍分别排在后续组。
